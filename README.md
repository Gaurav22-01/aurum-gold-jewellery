# Aurum & Co. — Gold Jewellery Website

A responsive demo jewellery storefront built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop, tablet and mobile layouts
- Mobile navigation and product search
- Category filters and collection shortcuts
- Demo add-to-bag count and wishlist buttons
- Newsletter form interaction
- Product cards and jewellery imagery

## Run locally
Open `index.html` in your browser. An internet connection is needed for Google Fonts and the remote Unsplash photos.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `aurum-gold-jewellery`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub will show your public website URL on the Pages settings screen, usually `https://YOUR-USERNAME.github.io/aurum-gold-jewellery/`.

## Before using for a real business
This is a front-end demo. The product names, descriptions and prices are sample content. The bag, wishlist and newsletter interactions are not connected to a backend, payment system, or email service. Replace sample details and imagery with approved business content. Avoid making purity, hallmarking or product claims unless verified.
